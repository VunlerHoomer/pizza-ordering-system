| 无会话、零编号、非法角色、角色不匹配 | 所有受限操作拒绝，业务函数调用次数不变 | C 核心断言通过 |
| 密码错误、顾客通过店长入口登录 | 不建立会话 | 通过 |
| 认证模块错误返回角色、账号或零编号 | A 拒绝该结果 | 通过 |
| 退出登录后再失败登录 | 不保留旧顾客身份 | 通过 |
| 正常程序输入演示凭据 | 不接受测试替身账户 | 通过 |
| 150 次登录/退出登录循环 | 无递归累积导致的异常，正常退出 | 通过 |
| 空输入、字母、小数、越界、超长行、嵌入 NUL | 拒绝并恢复到下一次完整输入 | 通过 |
| 最大合法文本长度、LF/CRLF、末行无换行 | 不丢字、不吞掉下一行 | 通过 |
| 金额 12.3 / 0.01 / int64 最大可表示分值 | 精确转换为 1230 / 1 / INT64_MAX | 通过 |

## 范围限制

角色、模块调用、加载/保存故障测试使用 `tests/demo_modules.c` 测试替身。
这不证明真实身份验证、订单/余额修改、文件持久化或销售统计已实现，也不证明真实磁盘故障下的一致性。
正常程序目前连接 B–E 的未实现占位函数；已验证其不会冒充登录成功。

Windows GCC、PowerShell 脚本、Windows `.exe` 运行未在本机执行；需 Windows 组员补充验证。
完整作业仍需所有真实模块的单元测试及端到端验收。
