# 报告写作模板

状态：提纲，尚非最终报告。根据实际代码和真实测试结果填写。

## 封面
项目名称、课程、五名成员姓名和学号、组长。

## 1. Problem Specification（A 主笔）
使用场景、系统用户、功能范围和目标。区分任务书要求与小组自行确定的规则。

## 2. Analysis（B 主笔，E 补充存储设计）
明确需求、账户和权限规则、定价、数据结构、文件格式、异常处理及设计理由。

## 3. Algorithm Design（C 主笔，A/D 补充）
整体模块图、接口和数据传递、定价流程、下单扣款与保存流程、主要算法。

## 4. Testing（E 主笔，全员提供证据）
测试环境、模块测试、集成测试、预期/实际结果、错误修复及复测。
以表格列出老师演示所需的测试用户名和密码（仅虚构演示账户）。

## 附：操作说明
构建环境、启动步骤、数据文件路径、顾客与店长操作、已知限制。
整理为提交包中的 manual；最终报告导出 PDF。
